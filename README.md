# جمعية الأسرة السعيدة · Den Glada Familjen

موقع تعريفي (Landing Page) ثنائي اللغة لجمعية **الأسرة السعيدة / Föreningen Den Glada Familjen** في فيستيروس، السويد.

الموقع مبني باستخدام **Astro** كموقع ثابت (Static Site) وجاهز للنشر على **Cloudflare Pages**، مع لوحة تحكم على `/admin/` تعدّل المحتوى **مباشرة إلى GitHub** — بدون Worker وبدون قاعدة بيانات.

---

## المحتوى

- صفحة عربية رئيسية على `/` (RTL)
- صفحة سويدية على `/sv/` (LTR)
- تبديل اللغة في الهيدر والقائمة
- تصميم Mobile First يعمل على الهاتف والتابلت والكمبيوتر
- أقسام: الواجهة الرئيسية، القيم، من نحن، الأنشطة، اللقاء الأسبوعي، الشعار، المعرض، الانضمام، الأسئلة الشائعة، التواصل
- صفحة أسبوعية مستقلة: `/meetings/` و`/sv/moten/` تعرض لقاءات الأحد بتسلسل زمني (Timeline) مع المواضيع، الملخصات، الصور، والفيديو، وخريطة ثابتة خفيفة للموقع
- أزرار واتساب، بريد إلكتروني، يوتيوب، تيك توك
- نموذج تواصل يفتح تطبيق البريد الإلكتروني (`mailto:`) بدون خادم
- SEO: عناوين ووصف، Open Graph، Sitemap، Robots، JSON-LD، hreflang
- أداء وأمان: صور محسّنة، خطوط محلية، CSP وHeaders على Cloudflare
- إتاحة: Skip link، تركيز واضح، احترام `prefers-reduced-motion`، HTML دلالي
- **لوحة تحكم** على `/admin/` تعدّل كل المحتوى تقريبًا: النصوص العربية والسويدية، اللقاءات، الصور، الشعار، وبيانات التواصل

## التشغيل محليًا

يتطلب **Node.js 22.23.4 أو أحدث**.

```bash
npm install
npm run dev
```

ثم افتح:

- العربية: http://localhost:4321/
- السويدية: http://localhost:4321/sv/
- لوحة التحكم: http://localhost:4321/admin/

### أوامر مفيدة

```bash
npm run check    # فحص TypeScript وأخطاء Astro
npm run build    # بناء الموقع إلى مجلد dist/
npm run preview  # معاينة نسخة الإنتاج محليًا
```

## لوحة التحكم `/admin/`

### كيف تعمل؟

```text
/admin (المتصفح)
   ↓  GitHub Token مشفّر بعبارة مرور محلية
GitHub API مباشرة من المتصفح
   ↓  commit إلى المستودع
Cloudflare Pages تعيد البناء تلقائيًا
   ↓
الموقع المحدّث خلال 1–2 دقيقة
```

- **لا يوجد Worker** ولا خادم وسيط.
- **لا توجد قاعدة بيانات**؛ المحتوى في ملفات المستودع.
- لا تُضبط أي متغيرات سرية في Cloudflare.
- الـ GitHub Token يبقى في المتصفح، مشفّرًا، ولا يُرسل إلى أي خادم غير GitHub.

### أول مرة: الإعداد

1. أنشئ **GitHub Fine-grained Token**:
   - GitHub → **Settings → Developer settings → Personal access tokens → Fine-grained tokens**
   - **Repository access:** Only select repositories → `eramax/Den-Glada-Familjen`
   - **Permissions → Repository permissions:**
     - **Contents: Read and write**
     - Metadata: Read-only (تلقائي)
   - اختر مدة صلاحية مناسبة (شهر إلى سنة) وفعّل تذكيرًا لتجديده.
2. افتح `https://den-glada-familjen.pages.dev/admin/`.
3. املأ:
   - **اسم العرض:** اسم يظهر في اللوحة فقط (مثل `admin`).
   - **المستودع:** `eramax/Den-Glada-Familjen`.
   - **الفرع:** `main`.
   - **GitHub Token:** التوكن من الخطوة 1.
   - **عبارة المرور المحلية:** عبارة طويلة (10 أحرف على الأقل) تختارها أنت.
4. اضغط **اختبار الاتصال وحفظ الإعداد**.

يُشفَّر التوكن بـ **AES-GCM** ويُحفظ في `localStorage` داخل متصفحك. عبارة المرور نفسها لا تُحفظ.

### كلمة المرور أم التوكن؟

| الشيء | ما هو؟ |
| --- | --- |
| **اسم العرض** | اسم للعرض فقط. GitHub لا يتحقق منه. |
| **عبارة المرور المحلية** | مفتاح محلي لفك تشفير التوكن. ليست كلمة مرور على خادم. |
| **GitHub Token** | المفتاح الحقيقي الذي يقرأ ويكتب في المستودع. |

- **عبارة المرور ليست التوكن.**
- **لا توجد كلمة مرور جاهزة من عندنا**؛ أنت تختارها أول مرة.
- إذا نسيت عبارة المرور: اضغط **«نسيت عبارة المرور؟»** → سيُحذف التوكن المشفّر، وتعيد إدخال التوكن من جديد.

### الاستخدام

- **الرئيسية:** كل نصوص الصفحة الرئيسية بالعربية والسويدية (الواجهة، من نحن، الأنشطة، المعرض، الأسئلة، التواصل...).
- **اللقاءات:** إضافة/تعديل/حذف لقاء أسبوعي، مع صوره والفيديو.
- **صفحة اللقاءات:** موعد اللقاء، المكان، بطاقات التنسيق، ونصوص الأرشيف.
- **الهوية والتنقل:** اسم الجمعية، القائمة، نصوص إمكانية الوصول، والفوتر.
- **بيانات التواصل:** البريد، الهاتف، واتساب، يوتيوب، تيك توك، رقم التسجيل، المدينة، ورابط الخريطة.
- **الصور:** استبدال صور الموقع **والشعار** (`logo-full.png` و`logo-mark.png`).

داخل كل صفحة يوجد تبويب **العربية / Svenska** لتحرير اللغتين.

### الحفظ والنشر

- زر **حفظ ونشر** يُنشئ commit في GitHub فورًا.
- Cloudflare Pages تكتشف الـ commit وتبدأ البناء.
- يظهر التعديل عادة خلال **1–2 دقيقة**.
- البناء نفسه سريع؛ الانتظار من خط نشر Cloudflare.
- إذا فشل البناء، يبقى آخر نشر ناجح ظاهرًا. راجع الـ commit على GitHub لتصحيح الخطأ.

### الأمان

- التوكن مشفّر بـ **PBKDF2-SHA256 (210,000 تكرار) + AES-GCM**.
- التوكن يُفكّ في الذاكرة فقط أثناء الجلسة، ولا يُكتب كنص في `localStorage`.
- زر **قفل** يمسح التوكن من الذاكرة؛ تحتاج عبارة المرور لفتحه مجددًا.
- استخدم جهازًا موثوقًا ومتصفحًا نظيفًا. أي XSS أو إضافة متصفح خبيثة قد تسرق التوكن أثناء فكّه.
- اجعل التوكن **Fine-grained** ومقصورًا على هذا المستودع، وقصير الصلاحية.
- فعّل 2FA على GitHub، وأبطل التوكن فورًا إذا شككت في تسربه.
- معاينة الصور تستخدم `raw.githubusercontent.com`، لذا يجب أن يكون المستودع **عامًا** (هو كذلك). الحفظ يعمل حتى لو كان خاصًا، لكن المعاينة قد لا تظهر.
- لا تستخدم اللوحة على جهاز مشترك دون قفلها وحذف الإعداد بعد الاستخدام.

### استكشاف الأخطاء

| المشكلة | السبب المحتمل | الحل |
| --- | --- | --- |
| «التوكن غير صالح أو منتهي» | انتهت صلاحية التوكن أو أُبطل | أنشئ توكنًا جديدًا وأعد الإعداد |
| «المستودع غير موجود أو التوكن لا يملك صلاحية الوصول» | اسم المستودع خطأ أو التوكن لا يملك صلاحية | صحّح `owner/repo` أو صلاحيات التوكن |
| «لا توجد صلاحية كافية» | التوكن بلا **Contents: Read and write** | عدّل صلاحيات التوكن |
| «تم تعديل الملف من مكان آخر» | تعديل متزامن من مكان آخر | أعد تحميل الصفحة ثم أعد الحفظ |
| الحفظ ينجح لكن الموقع لا يتحدّث | Cloudflare Pages غير مرتبط بالمستودع | فعّل Git integration أو أعد النشر |
| معاينة الصور لا تظهر | المستودع خاص | اجعل المستودع عامًا أو تجاهل المعاينة |

## تعديل المحتوى

المحتوى في ملفات داخل `src/content/`، ولوحة `/admin/` هي الطريقة الموصى بها. يمكنك أيضًا تعديل الملفات مباشرة على GitHub.

| الملف | الاستخدام |
| --- | --- |
| `src/content/pages/home.md` | نصوص الصفحة الرئيسية (ar + sv) |
| `src/content/pages/meetings.md` | نصوص صفحة اللقاءات (ar + sv) |
| `src/content/pages/site.md` | الهوية، القائمة، الفوتر، إمكانية الوصول (ar + sv) |
| `src/content/meetings/YYYY-MM-DD.md` | لقاء أسبوعي واحد (عربي + سويدي) |
| `src/content/settings.json` | البريد، الهاتف، واتساب، يوتيوب، تيك توك، رقم التسجيل، المدينة، رابط الخريطة |
| `src/data/site.ts` | يقرأ `settings.json` ويصدّر `SITE` للمكونات |
| `src/i18n/ar.ts` / `sv.ts` | قيم احتياطية فقط إذا نقص مفتاح من MD |
| `src/assets/images/` | الصور والشعار |
| `src/styles/global.css` | الهوية البصرية، الألوان، المسافات، التجاوب |
| `src/pages/` | الصفحات ونقطة `robots.txt` |
| `public/` | الأيقونات، صور OG، `_headers`، `_redirects` |

### تحديث اللقاءات الأسبوعية

**من لوحة التحكم:** تبويب **اللقاءات** → **+ إضافة لقاء** → املأ التاريخ والوسم والموضوع والملخص → ارفع صورة واحدة على الأقل → **حفظ ونشر**.

**يدويًا:** أضف ملفًا جديدًا في `src/content/meetings/YYYY-MM-DD.md` بنفس بنية الملفات الحالية.

كل أحد من **16:00 إلى 21:00** في مقر الجمعية:

**ABF-huset — Pilgatan 2, Västerås**

اللقاءات بالتعاون مع **ABF**، وتشمل ضيافة (fika)، موقف سيارات، والأطفال مرحب بهم.

### الصور والشعار

- تبويب **الصور** يستبدل صور الواجهة ومن نحن والمعرض والشعار.
- الصور تُضغط تلقائيًا قبل الرفع (حد أقصى 4MB).
- الشعار يفضل أن يكون PNG بخلفية شفافة.
- صور اللقاءات تُرفع من محرر اللقاء.
- الصور الحالية تعبيرية من [Pexels](https://www.pexels.com/)؛ يُفضّل استبدالها بصور حقيقية من أنشطة الجمعية.

## النشر على Cloudflare Pages

1. ارفع المشروع إلى GitHub.
2. من Cloudflare Dashboard: **Workers & Pages → Create → Pages → Connect to Git**.
3. اختر المستودع.
4. الإعدادات:
   - **Framework preset:** Astro (أو None)
   - **Build command:** `npm run build`
   - **Build output directory:** `dist`
   - **Environment variable:** `NODE_VERSION = 22.23.4`
   - **Environment variable (اختياري):** `SITE_URL = https://your-domain.com` للنطاق المخصص
5. اضغط **Save and Deploy**.

> لا حاجة إلى `functions/` أو Workers أو أي متغيرات سرية للوحة التحكم. اللوحة صفحة ثابتة تتصل بـ GitHub API مباشرة.

### النطاق المخصص

1. من مشروع Pages: **Custom domains → Set up a custom domain**.
2. أضف النطاق واتبع تعليمات DNS.
3. أضف `SITE_URL` في متغيرات البيئة ثم أعد النشر.

> ملف `public/_headers` يضيف ترويسات أمان وCSP، وملف `public/_redirects` يعالج روابط `/ar`.

## ملاحظات مهمة

- **الصور:** الصور الفوتوغرافية الحالية تعبيرية من Pexels. استبدلها بصور حقيقية من اللقاءات عبر تبويب «الصور» أو محرر اللقاء.
- **اللقاءات الأسبوعية:** المحتوى في `src/content/meetings/`. أضف لقاءً جديدًا من اللوحة أسبوعيًا، وحدّث الوسم («غدًا» / «الأحد الماضي») بعد انتهاء اللقاء.
- **نموذج التواصل:** لا يوجد خادم للبريد. النموذج يفتح تطبيق البريد الإلكتروني لدى الزائر عبر `mailto:`.
- **الخصوصية:** الموقع العام لا يستخدم كوكيز أو أدوات تتبّع. لوحة الإدارة تستخدم `localStorage` لتخزين التوكن المشفّر فقط.
- **البيانات:** رقم التسجيل والبريد والهاتف أصبحت قابلة للتعديل من تبويب **بيانات التواصل**.
- **الخريطة:** خريطة ثابتة خفيفة من OpenStreetMap محفوظة محليًا في `src/assets/images/map-pilgatan.png` مع علامة الموقع، وتفتح خرائط Google عند الضغط. لا iframe ولا طلبات خارجية وقت التحميل. الإسناد: © OpenStreetMap contributors.
- **CSP والخطوط:** سياسة `_headers` تسمح بـ `font-src 'self' data:` لأن Astro/Vite يضمّن بعض ملفات الخطوط الصغيرة كـ data URI. الخطوط ما زالت محلية بالكامل.
- **تفاعل الواجهة:** تم تعطيل تحديد النص في عناصر الواجهة للحفاظ على مظهر تطبيقي، مع إبقاء حقول الإدخال وبيانات التواصل قابلة للنسخ.
- **الترجمة:** النصوص السويدية والعربية مكتوبة يدويًا؛ يُنصح بمراجعة لغوية سريعة من متحدث أصلي قبل الإطلاق.
- **تعدد المحررين:** لا يوجد قفل تحرير. إذا عدّل شخصان الملف نفسه، سيرفض GitHub الحفظ الثاني ويطلب إعادة التحميل.

│   ├── pages/                  # / و /sv/ و /admin/
